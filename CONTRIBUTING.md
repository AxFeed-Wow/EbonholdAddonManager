\# Contributing to Ebonhold Addon Manager



Thank you for your interest in contributing to Ebonhold Addon Manager.



Contributions, bug reports, documentation improvements and feature suggestions are welcome.



\## Before contributing



Please check the existing issues and pull requests before opening a new one.



For significant changes, opening an issue first is recommended so the proposed approach can be discussed before implementation.



\## Reporting bugs



When reporting a bug, please provide as much relevant information as possible:



\* A clear description of the problem

\* Steps to reproduce it

\* What you expected to happen

\* What actually happened

\* Your Windows version

\* The Ebonhold version, when relevant

\* Relevant error messages or logs

\* Screenshots, when useful



Please avoid including personal information, authentication credentials or sensitive data in bug reports.



\## Feature requests



Feature requests are welcome.



Please explain:



\* What problem the feature would solve

\* How you expect it to work

\* Why it would be useful to Ebonhold Addon Manager



Keep in mind that the project aims to remain lightweight and focused on addon management.



\## Pull requests



Before opening a pull request:



1\. Make sure your changes are focused on the proposed feature or fix.

2\. Avoid unrelated changes.

3\. Make sure the project builds successfully.

4\. Test the affected functionality when possible.

5\. Update the documentation when necessary.

6\. Keep third-party addon code out of this repository unless its inclusion is explicitly permitted and appropriate.



Pull request descriptions should explain what was changed and why.



\## Code style



Please follow the existing coding style and conventions used by the project.



In particular:



\* Prefer clear and descriptive names.

\* Keep methods focused on a single responsibility.

\* Avoid unnecessary dependencies.

\* Handle errors explicitly where appropriate.

\* Avoid hard-coded user-specific paths.

\* Do not commit generated build files.



\## Third-party addons



Ebonhold Addon Manager references third-party addons hosted in their respective repositories.



Contributors must not copy third-party addon source code into this repository unless there is a clear legal basis and a specific reason to do so.



When modifying `addons.json`, make sure repository information is accurate and points to the appropriate upstream repository.



\## Security issues



Please do not report security vulnerabilities through public GitHub issues.



See \[SECURITY.md](SECURITY.md) for the appropriate reporting procedure.
