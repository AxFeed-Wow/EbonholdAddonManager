# Security Policy

**English** | [Français](#politique-de-sécurité)

## Supported versions

Security fixes are generally provided for the latest version of Ebonhold Addon Manager. Older versions may not receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability, please report it privately through the security features provided by the GitHub repository when available.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant logs, screenshots or proof of concept
* The version of Ebonhold Addon Manager affected

Please do not include passwords, access tokens, personal information or other sensitive data in the report.

## What to expect

Security reports will be reviewed as soon as reasonably possible. If the issue is confirmed, appropriate measures will be taken to fix it and prevent similar issues where possible. Public disclosure should preferably wait until a fix or mitigation is available.

## Scope

This policy applies to the Ebonhold Addon Manager application and its own source code.

Third-party addons, GitHub repositories and external services referenced by the application are maintained by their respective owners and should be reported to them when the issue originates from those components.

# Politique de sécurité

[English](#security-policy) | **Français**

## Versions prises en charge

Les correctifs de sécurité sont généralement fournis pour la dernière version d'Ebonhold Addon Manager. Les versions plus anciennes peuvent ne pas recevoir de mises à jour de sécurité.

## Signaler une vulnérabilité

Ne signale pas de vulnérabilités de sécurité via des issues GitHub publiques.

Si tu penses avoir trouvé une vulnérabilité, signale-la en privé via les fonctionnalités de sécurité du dépôt GitHub lorsqu'elles sont disponibles.

En signalant une vulnérabilité, inclus :

* Une description claire de la vulnérabilité
* Les étapes pour reproduire le problème
* L'impact potentiel
* Tout log, capture d'écran ou preuve de concept pertinent
* La version d'Ebonhold Addon Manager concernée

N'inclus pas de mots de passe, jetons d'accès, informations personnelles ou autres données sensibles dans le rapport.

## À quoi s'attendre

Les rapports de sécurité seront examinés dès que raisonnablement possible. Si le problème est confirmé, des mesures appropriées seront prises pour le corriger et prévenir des problèmes similaires quand c'est possible. La divulgation publique devrait de préférence attendre qu'un correctif ou une mitigation soit disponible.

## Périmètre

Cette politique s'applique à l'application Ebonhold Addon Manager et à son propre code source.

Les addons tiers, dépôts GitHub et services externes référencés par l'application sont maintenus par leurs propriétaires respectifs et doivent leur être signalés lorsque le problème provient de ces composants.
