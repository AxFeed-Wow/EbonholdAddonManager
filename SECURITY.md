# Security Policy



## Supported versions



Security fixes are generally provided for the latest version of Ebonhold Addon Manager.



Older versions may not receive security updates.



## Reporting a vulnerability



Please do not report security vulnerabilities through public GitHub issues.



If you believe you have found a security vulnerability, please report it privately through the security features provided by the GitHub repository when available.



When reporting a vulnerability, please include:



* A clear description of the vulnerability

* Steps to reproduce the issue

* The potential impact

* Any relevant logs, screenshots or proof of concept

* The version of Ebonhold Addon Manager affected



Please do not include passwords, access tokens, personal information or other sensitive data in the report.



## What to expect



Security reports will be reviewed as soon as reasonably possible.



If the issue is confirmed, appropriate measures will be taken to fix it and prevent similar issues where possible.



Public disclosure should preferably wait until a fix or mitigation is available.



## Scope



This policy applies to the Ebonhold Addon Manager application and its own source code.



Third-party addons, GitHub repositories and external services referenced by the application are maintained by their respective owners and should be reported to them when the issue originates from those components.
